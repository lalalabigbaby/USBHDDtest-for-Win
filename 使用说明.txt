========================================================================
  移动硬盘稳定性测试 - 离线包 使用说明
  适用系统: Windows 7 / 8 / 8.1 / 10 / 11 (32位与64位均可)
  更新日期: 2026-08
========================================================================

一、离线包内容清单
------------------------------------------------------------------------
  HDD稳定性测试启动器.bat   主启动程序(双击运行这个)
  hdd_stability_test.py     硬盘测试脚本(自动被拷贝到目标盘, 无需手动操作)
  python-3.8.10-amd64.exe   Python 3.8.10 离线安装包(64位系统)
  python-3.8.10.exe         Python 3.8.10 离线安装包(32位系统)
  Windows6.1-KB2533623-x64.msu   Win7 x64 安装前置补丁
  Windows6.1-KB2533623-x86.msu   Win7 x86 安装前置补丁
  Windows6.1-KB3118401-x64.msu   Win7 x64 Universal C Runtime 补丁
  Windows6.1-KB3118401-x86.msu   Win7 x86 Universal C Runtime 补丁

整个文件夹可以拷到U盘/任意位置, 完全离线运行, 无需联网。


二、环境要求
------------------------------------------------------------------------
  1. 操作系统: Windows 7 SP1 及以上 (Win7/Win8/Win8.1/Win10/Win11)
  2. 首次运行需要"管理员权限"用于安装系统补丁和 Python
     (若系统已具备环境, 普通权限也可运行)
  3. 待测移动硬盘/U盘: 建议使用空盘或非重要数据盘
     (测试会写满整个磁盘! 重要数据请先备份!)


三、快速开始 (三步)
------------------------------------------------------------------------
  第1步: 把整个"离线包"文件夹拷贝到目标电脑
  第2步: 双击运行  HDD稳定性测试启动器.bat
  第3步: 按屏幕提示操作:
         - 若提示UAC授权, 选择"是"
         - 输入要测试的磁盘编号
         - 输入测试轮次(建议 1-10)
         然后程序自动完成: 环境安装 -> 拷贝脚本 -> 写满测试 -> 校验 -> 清理


四、程序自动完成的四步流程
------------------------------------------------------------------------
  [1/4] 检查并安装系统补丁
         - 检测 KB2533623、KB3118401 是否已安装
         - 缺失时用 wusa 静默安装对应位数的离线补丁包
         - Win8/10/11 系统自带这些组件, 会自动跳过

  [2/4] 检查并安装 Python 3.8
         - 若系统已有 Python 3.x, 直接使用现有版本
         - 若缺失, 静默安装 python-3.8.10 (按系统位数自动选择)

  [3/4] 枚举并选择磁盘
         - 列出所有"可移动磁盘"(U盘)和"本地磁盘"(含USB移动硬盘)
         - 自动排除系统盘(装有Windows的盘)
         - 输入编号选择要测试的磁盘

  [4/4] 设定轮次并运行测试
         - 输入测试循环次数(1-9999, 建议1-10)
         - 自动把测试脚本拷贝到所选磁盘根目录并运行
         - 测试过程中请勿拔出硬盘!


五、测试脚本工作原理
------------------------------------------------------------------------
  每轮流程: 写满磁盘 -> 全0xFF校验 -> 删除临时文件 -> 进入下一轮
  - 文件大小自动降级: 256MB -> 128MB -> 64MB -> 32MB -> 16MB
  - 校验: 全1字节比对(位翻转即失败), 失败会记录到日志但继续测试
  - 日志: 保存到 C:\HDD_Test_Logs 或 D:\HDD_Test_Logs (其他磁盘, 防丢失)
  - 测试完成后日志自动复制一份到被测盘根目录
  - 日志文件名: HDD_Stability_盘符_时间戳.log


六、常见问题排查
------------------------------------------------------------------------
  Q1: 提示缺少 api-ms-win-crt-runtime-l1-1-0.dll
      -> 说明 Universal C Runtime 未安装, 运行本程序会自动装 KB3118401
         (若已装仍报错, 请重启系统后再试)

  Q2: 安装补丁提示"此更新不适用于您的计算机"
      -> 说明系统已包含该组件(Win8+/Win10/11 或已打齐补丁的Win7),
         属正常现象, 可跳过继续

  Q3: Python 安装失败(错误码1603)
      -> 一般是系统补丁未生效, 重启系统后重新运行本程序
      -> 或检查是否以管理员身份运行

  Q4: 没检测到我的移动硬盘
      -> USB移动硬盘通常显示为"本地磁盘", U盘显示为"可移动磁盘"
      -> 请确认硬盘已连接且被系统识别(我的电脑里能看到盘符)
      -> 本程序排除了系统盘, 若你的移动硬盘被分配了系统盘符
         (极少见), 请手动调整

  Q5: 测试速度比标称值慢
      -> 正常现象: 本测试每64MB执行一次强制落盘(fsync),
         目的是验证真实写入, 速度不代表硬盘理论极限

  Q6: 提示"检测到其他实例正在运行"
      -> 同一块盘不允许同时跑两个测试(锁文件机制)
      -> 若确认没有其他测试在跑, 可删除被测盘根目录的 .hdd_test.lock 文件

  Q7: 批处理界面中文显示乱码
      -> 批处理为GBK编码, 请确认系统区域为中文(中国大陆)
      -> 或 cmd 窗口执行: chcp 936


七、多块硬盘同时测试
------------------------------------------------------------------------
  支持: 在多块移动硬盘上分别放置本离线包(或共享一个包),
         同时运行多个启动器实例, 每块盘互不干扰。
  注意: 多盘同时测试会争抢USB总线带宽, 测得的速度会互相拉低,
        属正常物理现象, 不代表硬盘有问题。


八、手动运行测试脚本(可选, 高级用户)
------------------------------------------------------------------------
  若已安装Python, 可手动运行(脚本需在待测盘根目录):

    python hdd_stability_test.py                交互模式(输入轮次+确认)
    python hdd_stability_test.py -c 5           直接跑5轮
    python hdd_stability_test.py -c 5 -y        5轮, 全自动(无交互)

  参数说明:
    -c, --cycles N   测试轮次(1-9999), 缺省为交互输入
    -y, --yes        自动确认, 跳过所有等待输入


九、安全提示
------------------------------------------------------------------------
  !!! 测试会把所选磁盘完全写满(仅保留16MB), 属于高强度压力测试 !
  - 请务必使用 空盘 或 不含重要数据 的硬盘
  - 测试中不要拔出硬盘、不要强制断电
  - 测试后建议在"我的电脑"中检查磁盘是否正常
  - 若校验出现失败, 说明硬盘存在写入错误/坏道, 请及时备份并更换硬盘
